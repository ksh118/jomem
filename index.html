처음 오셨나요?

자주 묻는 질문

시참은 어떻게 해요?

조밈 디스코드 서버에 들어온 다음 '역할' 채널에서 '시참 참여하기' 버튼을 누르면 돼요. 서버 주소랑 버전은 '서버주소' 채널에 올라와 있어요.

서버 주소랑 마크 버전은 어디서 봐요?

디스코드 '서버주소' 채널에서 확인해주세요. 정확한 주소와 버전으로 접속해야 해요.

접속이 안 되거나 오류가 나요.

채팅창에 물어보지 말고 디스코드 문의 채널에 남겨주세요. 채팅창 질문은 채팅 규칙 위반이에요.

게임하는 동안 방송을 켜둬야 해요?

네. 컨텐츠에 참여하는 동안에는 방송 음성을 꼭 들으면서 참여해주세요.

규칙을 몰랐으면 봐주나요?

아니요. 규칙을 읽지 않아 생긴 불이익은 본인 책임이에요. 시참 전에 채팅 규칙이랑 참여 규칙은 꼭 읽어주세요.

야생 배틀로얄

게임 방식

게임이 시작되면 무적 시간 15분이 주어짐

15분동안 야생에서 자유롭게 파밍 후, 무적 시간이 끝나면 PVP 진행

PVP가 진행되는 동안, 자기장이 x=0, y=0 좌표를 기준으로 줄어듦

4차 자기장까지 줄어들게 되면 데스매치장으로 이동 후, 데스매치 진행

최후의 1인은 우승

학교 술래잡기

게임 방식

게임이 시작되면 도망자는 학교에서 생존해야 함

도망자는 북도에서만 생성 되는 금을 획득 후, 특수 아이템으로 교환 가능

술래가 맵에 설치된 발전기를 모두 파괴하면 도망자에게 어둠 디버프와 주기적인 발광 효과가 적용됨

파괴된 발전기는 도망자가 수리할 수 있음 (수리 완료 시, 금 8개 지급)

도망자는 맵 곳곳에 배치된 구급함을 열면 특별한 아이템 획득 가능

제한 시간이 끝날 때까지 도망자가 생존하면 도망자 승리 도망자 전원이 탈락하면 술래 승리

  • ×고의적인 트롤
